### ✦ Who's this?

I am a Human. No titles here. No resume. Just someone who loves technology,
spends too much time thinking about solving problems with TECH, and believes the best
way to understand something is to **build it**.

---

### 🔭 What I'm into

| | |
|---|---|
| 🧠 **Artificial Intelligence** | LLMs, agents, and what's coming next |
| 🧪 **Experiments** | Quick prototypes to test "what if" ideas |
| 🌍 **Open Source** | Contributing to the tools I use and admire |
| ⚡ **Tech in general** | If it's new and interesting, I'm poking at it |

### 🧪 How I work

```txt
while (curious) {
  build();
  break_things();
  learn();
  contribute();
}
```

> Curiosity first, perfection later.
> Every broken build teaches something.
> Small contributions add up.
